LALIT SAINI PORTFOLIO — LIGHT EDITION (NO PROFILE PHOTO)

FILES
- index.html — website content and sections
- style.css — layout, responsive styles, and light green theme
- script.js — mobile menu, scroll reveal, current year, and edit shortcut

PREVIEW ON YOUR COMPUTER
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser (or use the Live Server extension).

UPDATE YOUR EXISTING GITHUB PAGES WEBSITE
1. Download and extract this ZIP.
2. Open your repository: https://github.com/sainilalit19832007-design/Lalit-Saini-Portfolio
3. Replace the existing index.html, style.css, and script.js with these versions.
4. Commit the changes. GitHub Pages will publish the update automatically after a short delay.

EDIT SHORTCUT
Append ?owner=1 to your live portfolio URL to reveal “Edit my site”. It opens the index.html editor on GitHub. You must sign in with an account that has write access to save changes. This only hides the button from the normal page view; it is not secure authentication by itself.

LINKEDIN
In index.html, search for id="linkedinLink" and replace the generic LinkedIn URL with your own profile URL when ready.

CONTENT NOTE
The page uses the details already in your existing portfolio and does not include a profile photo.
